Frequently Asked Questions

What engine powers Aura's analysis?

Aura utilizes Dropbox's industry-standard zxcvbn library, which evaluates password strength using pattern matching and entropy calculations. This engine simulates real-world attack scenarios to give you accurate security assessments.

Does this tool attempt to login anywhere?

Absolutely not. Aura performs 100% client-side analysis only. Your password never leaves your device, and no login attempts are made to any service. This is a pure security assessment tool.

How are data breaches detected?

Passwords are checked against the Have I Been Pwned database using k-Anonymity protocol. This means only the first 5 characters of your password's hash are sent, ensuring your actual password remains completely private.

What do the scores mean?

Scores range from 0-100%: 0-25% (Very Weak), 25-50% (Weak), 50-75% (Moderate), 75-100% (Strong to Very Strong). A strong password should score at least 75% with high entropy and no breach history.

Is my data stored anywhere?

Analysis metadata (score, crack time, account type) is stored for statistical purposes only. Your actual password is hashed and checked against breach databases but never stored in plaintext anywhere.
